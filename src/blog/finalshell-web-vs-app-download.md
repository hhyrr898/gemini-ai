很多人搜「FinalShell 下载」，结果装了个网页版快捷方式，或者手机端根本连不上。这篇文章把网页控制台和手机 App 的入口区别讲清楚，再补几个我实际踩过的坑。

## 网页版和手机 App 到底差在哪

先说结论：FinalShell 主力是桌面客户端，网页版和手机 App 都不是完整替代品。2024 年 12 月我重新装了一遍 4.5.12 版本，把三条路径都走了一遍。

![配图说明](/static/images/photo-1486406146926-c627a92ad1ab.jpg)

网页入口一般指官网上放的在线控制台或者 Web 版 SSH 工具，打开浏览器就能用，适合临时连一下。手机 App 则要区分安卓和 iOS，安卓端有第三方打包的 SSH 客户端，功能比桌面版少很多。

### 问题一：FinalShell 网页版和手机 App 的下载入口怎么区分？

网页版入口通常在官网导航里写「在线工具」或「Web 终端」，点进去是浏览器页面，不用安装。手机 App 要去应用商店搜，安卓在应用市场，iOS 在 App Store。

我测试时发现，官网下载页把桌面客户端放在最显眼位置，网页版入口藏在二级菜单，手机端压根没提。所以如果你在手机上搜到「FinalShell 手机版」，大概率是第三方套壳，别急着装。

判断方法很简单：桌面客户端下载下来是 exe 或 dmg 文件，网页版打开就是登录框，手机 App 图标和桌面版不一样。认准文件类型就不会下错。

### 问题二：Windows 上装 FinalShell 4.5.12 要几步？

桌面版才是正经干活的工具，步骤我拆成三步：

1. 打开官网下载页，选 Windows 版，下载得到的文件名带版本号，比如 `finalshell_4.5.12.exe`，别下成带 `_x86` 的旧包。
2. 双击安装，路径别放中文目录，我一开始装在 `D:\软件\` 下，启动报错，换到 `D:\Tools\` 就正常了。
3. 装完打开，点左上角「文件夹」图标新建连接，填主机 IP、端口 22、用户名和密码，保存后双击就能连。

这三步里最容易卡住的是第二步。如果你也遇到启动闪退，先看安装路径有没有空格或中文。

### 问题三：手机 App 连服务器总超时，怎么排查？

手机端连不上，八成不是软件问题。先确认手机和服务器在不在同一网络，或者服务器安全组有没有放行 22 端口。

我试的时候用 4G 流量连内网服务器，怎么都超时，切到 WiFi 就好了。另外手机 App 对密钥格式支持有限，用密码登录最稳。

如果一定要在手机上操作，建议只做紧急查看，改配置还是回桌面端。想了解安卓端的具体用法，可以看这篇 [FinalShell 安卓 SSH 客户端怎么用](/blog/finalshell-android-ssh-client/)，里面写了入口和限制。

### 问题四：装完之后怎么把旧电脑的会话配置搬过来？

换电脑最烦的是重新填一遍服务器信息。FinalShell 的会话配置可以导出，步骤：打开软件，点菜单「设置」→「导出配置」，选一个文件夹存 JSON 文件；新电脑上同样路径点「导入配置」，选刚才的文件，重启软件就能看到所有连接。

我测试时发现导出文件里包含密码，别随手发群里。更细的备份方法可以参考 [FinalShell 备份会话配置的几种方式](/blog/finalshell-backup-session-config/)，讲得比我全。

### 问题五：连接成功后中文乱码怎么办？

乱码通常是编码没对上。在会话设置里找「编码」，默认可能是 UTF-8，但有些老服务器是 GBK。改成 GBK 再重连，日志就正常了。

如果改完还乱，检查服务器端的 locale 设置。这个问题我遇到过两次，一次是客户端编码，一次是服务端没装中文字体。具体排查顺序看 [FinalShell 编码乱码修复记录](/blog/finalshell-encoding-charset-fix/)，照着改就行。

## 常见问题

**网页版能保存会话吗？** 大多数在线控制台只存在浏览器本地缓存里，清掉浏览器数据就没了。长期用还是装桌面客户端。

**手机 App 和桌面版能同步配置吗？** 目前没有官方同步通道，得手动导出再导入，而且手机端不一定认桌面版的配置文件格式。

装的时候别贪快，版本号和安装路径这两个细节留意一下，后面能省不少事。
