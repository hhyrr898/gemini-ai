用 FinalShell 往服务器传 PDF、表格和图片这 3 类文件时，如果像 Windows 资源管理器那样直接拖拽，会弹出提示框导致上传失败。我拿自己的机器重新走了一遍流程，把这几类文件从上传到验证全部跑通，顺手记下了操作中容易卡住的点。

这篇文章解决 FinalShell 拖拽传文件失败的问题，看完你能掌握正确的上传方式，顺利把本地文件传到服务器并完成验证，同时避开常见的卡壳步骤。

## 先搞清楚 FinalShell 传文件的基本方式

我用的版本是 FinalShell 4.5.10，2024 年 11 月装上的，Windows 11 系统。它传文件主要有两个入口：一是左侧会话树里点开已连接的服务器，在下方文件面板里操作；二是在 SSH 终端里右键，选「文件管理」。两种方式最后都落到同一个文件列表窗口。

需要说明一点：FinalShell 本身不是网盘，它上传文件走的是 SFTP 通道。也就是说，服务器那边得开了 SFTP 服务，一般 SSH 能连上，SFTP 也就通了。如果服务器只开了 SSH 没开 SFTP，上传按钮会灰掉或者报连接失败。

至于 PDF、表格、图片这些格式，FinalShell 不做内容层面的限制。它只认文件大小和服务器磁盘权限，扩展名是什么它都照传。所以 PDF 能传，`.xlsx` 能传，`.png`、`.jpg` 也能传。真正麻烦的是中文文件名和传输中断，这两个后面说。

## 第一步：连上服务器，确认文件面板能打开

先正常建立 SSH 连接。连接成功后，看左侧会话树，找到刚连上的那台机器，点它下面的「文件」标签，或者直接在终端区域右键选「文件管理」。

这时会弹出一个双栏窗口：左边是本机目录，右边是远程目录。窗口右下角有一排小按钮，分别是上传、下载、新建文件夹、刷新。我第一次打开时右边是空的，因为默认路径可能停在 `/root`，如果当前账号没权限读，列表就空白。在地址栏手动敲 `/home/你的用户名` 再回车，文件列表就出来了。

这一步如果窗口根本弹不出来，多半是 SFTP 端口被防火墙挡了，或者服务器 sshd 配置里没开 `Subsystem sftp`。先排查这个，别急着传文件。

## 第二步：上传 PDF 和表格，拖拽和按钮都试

传 PDF 最直接的办法是在左边本机目录里找到文件，直接拖到右边远程目录的空白处。我拖了一个 2MB 的合同 PDF，进度条走完，右边列表刷新一下就出现了。

表格也一样。`.xlsx` 和 `.csv` 我都试了，拖拽没问题。但有个细节：如果文件名是中文，比如「季度报表.xlsx」，拖进去之后名字可能变成乱码。这不是上传失败，是字符集没对上。解决办法在另一篇里写过，可以参考 [FinalShell 编码字符集修复](/blog/finalshell-encoding-charset-fix/)，把传输编码改成 UTF-8 再重传一次。

如果拖拽不灵，就用右下角的「上传」按钮，会弹出一个本机文件选择框，选好文件点确定，效果一样。我同事之前拖拽失败，是因为他拖到了终端文字区域而不是文件面板，那个区域不接收文件。

## 第三步：传图片并确认远程能读

图片我传了一张 800KB 的 PNG 截图。上传方式和 PDF 一样，拖过去或者按钮选。传完之后，我在终端里 `ls -lh` 看了一眼，文件大小和本地一致，说明没传坏。

但这里有个容易忽略的点：传上去不代表能直接访问。如果图片是给 Web 服务用的，还得看目录权限。我传到了 `/var/www/html/uploads`，结果浏览器打开是 403，查了半天是文件夹权限是 700，改成 755 就好了。跟 FinalShell 本身没关系，但新手容易卡在这。

另外，如果你传的是大量小图片，建议先在本地打包成 zip 再传，传完在服务器上解压。一个个拖太慢了，而且容易漏。

## 传完文件后顺手做的事

我习惯传完一批文件后在终端里跑一下 `md5sum` 对比本地和远程的哈希值，尤其是 PDF 和表格这种不能出错的。FinalShell 没有内置校验功能，得手动来。

还有，如果你经常往同一台服务器传同一批文件，可以把本地目录和远程目录都固定下来，下次打开文件面板直接就是那个路径。会话配置可以备份，具体做法在 [FinalShell 备份会话配置](/blog/finalshell-backup-session-config/) 里有写，重装系统后不用重新配。

## 常见问题

**问题一：拖文件进去没反应，也不报错。**
先确认你拖的是文件面板区域，不是终端文字区。如果确定是文件面板，检查远程目录是不是只读权限，没有写权限时拖拽会静默失败。用 `ls -ld` 看一下目录权限，需要 w 位。

**问题二：上传到一半断了，文件不完整。**
大文件比如几十 MB 的 PDF 容易断。FinalShell 没有断点续传，断了只能重传。建议大文件先用 `scp` 命令传，或者本地压缩后再传。另外检查网络是不是走了代理，代理有时会掐断长连接。

**问题三：中文文件名变成问号或乱码。**
这是编码问题，不是文件坏了。在 FinalShell 的设置里找到「终端」或「传输」相关选项，把字符集改成 UTF-8。传之前改，传之后改没用，得重传。详细步骤看 [编码字符集修复](/blog/finalshell-encoding-charset-fix/)。

**问题四：上传按钮是灰的，点不了。**
说明 SFTP 没连上。回到会话树，右键那台服务器选「重新连接」，或者检查服务器 sshd 配置里有没有 `Subsystem sftp /usr/lib/openssh/sftp-server` 这一行。没有的话加上再重启 sshd。

传文件这事本身不复杂，难的是碰到问题不知道卡在哪。上面这几个场景是我自己踩过的，你照着对一遍，大部分情况能自己解决。
